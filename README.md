# Yamaha Projects Dashboard

Performance review for five Yamaha programs. Open `index.html` in a browser. No install or server is required.

The page uses the Yamaha wordmark and a white layout. Figures in the dashboard are sample data for review, not live program results.

## Programs

| Tab | What it reviews |
| --- | --- |
| Tie-Up | Partner placements and co-branded activity |
| Local Mechanics | Workshop jobs and genuine-parts offtake |
| Pulse Card | Card issuance, redemption, and outlet activity |
| Influencer | Creator delivery and campaign results |
| Kizuna | Member attendance and chapter activity |

## Period filter

The month control covers fiscal year 2026–27 from April through October:

- **FY to date** — April through October
- **Jul–Sep** — the quarter review
- **Apr** through **Oct** — a single month

October is month-to-date through 13 October 2026. Choosing a month, or clicking a bar in the chart, updates the period volume, year-on-year comparison, mix, rankings, activity counts, and takeaways. Growth is green when the period is up and red when it is down.
